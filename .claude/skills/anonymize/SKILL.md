# Ширма: обезличить, разобрать, вернуть обратно

Чтобы починить чужую программу, нужно увидеть её логи и конфиги. В них
живут ключи, пароли, телефоны и фамилии. Этот скилл закрывает разрыв:
секреты заменяются устойчивыми метками, разбор идёт на обезличенной копии,
а ответ разворачивается обратно по словарю замен.

**Словарь замен — единственное, что раскрывает скрытое.** Он остаётся у
владельца файлов. Никогда не прикладывай его к тому, что отправляешь
наружу, и не показывай в переписке.

## Когда применять

- заказчик прислал логи или исходники, и в них есть боевые доступы;
- нужно показать кусок лога в чате, в переписке на бирже или другому ИИ;
- перед отправкой файла хочется убедиться, что в нём не осталось секретов.

## Порядок

### 1. Свои слова

Шаблоны ловят типовое: токены, ключи, почту, телефоны, ИНН, адреса
серверов, домены, имена пользователей в путях. Название компании и фамилии
шаблоном не поймать — их нужно записать в `words.txt` рядом с программой,
по одному в строке:

```
Ромашка
Петрова
```

Падежи учитываются сами: «Петрова» поймает и «Петровой», и «Петрову».

### 2. Обезличить

```bash
python cli.py hide logs/app.log          # рядом появится app.log.anon
python cli.py hide src/ --out anon_src/  # всю папку, метки сквозные
```

Сквозные метки важны: одна и та же компания везде становится `NAME_1`,
один и тот же ключ — `KEY_1`, в том числе в разных файлах. Если этого не
сохранить, связи между логом и кодом рвутся и разбирать становится нечего.

### 3. Проверить перед отправкой

```bash
python cli.py check logs/app.log.anon
```

Возвращает ненулевой код, если что-то ещё похоже на секрет, — удобно
ставить в конвейер перед отправкой.

### 4. Разобрать и вернуть обратно

Работай с обезличенной копией: ищи причину, пиши правку. Когда ответ
готов, подставь настоящие значения:

```bash
python cli.py back ответ.txt             # рядом появится ответ.restored.txt
```

Если словарь лежит не рядом, укажи путь: `--map путь/anon.map.json`.

## Интерфейс вместо командной строки

```bash
python app.py        # откроется http://127.0.0.1:8765
```

Перетащил файлы — получил обезличенные копии, словарь и отчёт, что именно
скрыто. Те же три действия: скрыть, вернуть, проверить.

## Чего делать нельзя

- отправлять `anon.map.json` вместе с обезличенными файлами — это сводит
  на нет всю работу;
- полагаться на шаблоны вслепую: всегда прогоняй `check` перед отправкой
  и добавляй в `words.txt` то, что шаблон не знает;
- обезличивать двоичные файлы: изображения, архивы, базы — они
  пропускаются, и секреты внутри них останутся.

## Установка у себя

Нужен только Python 3.11 или новее. Внешних зависимостей нет.

```bash
git clone <адрес репозитория>
cd anonymizer
python -m unittest discover tests    # 15 проверок, должны пройти
python app.py
```
